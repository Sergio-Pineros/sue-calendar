## frequency-tone-generator

The Frequency tuner in SÚE adapts the Web Audio oscillator pattern
(`AudioContext` → `OscillatorNode` → destination, start/stop on a user
gesture) from [frequency-tone-generator](https://github.com/MichalAFerber/frequency-tone-generator)
by Michal Ferber. The original project is MIT-licensed. SÚE reimplements
that pattern in TypeScript with fade, volume, waveforms, an optional
binaural pair, and a SÚE-native UI. It does **not** include the original
project’s anecdotal medical / condition frequency chart.
